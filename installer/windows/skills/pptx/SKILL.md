# pptx 확인 절차

텍스트 추출만으로 판단하면 도형 배치·표 병합·이미지 안의 글자를 놓친다. 이미지와 텍스트를 항상 함께 본다.

## pptx 파일 확인 규칙

- **pptx 파일 내용을 확인할 때 pptx-mcp를 사용한다.**
- 이용 순서:
  1. pptx-mcp로 파일 열기
  2. pptx-mcp로 모든 슬라이드를 PNG 이미지로 저장
  3. pptx-mcp로 슬라이드 텍스트와 표 구조 추출
  4. 저장된 PNG 이미지를 Read 도구로 모두 열어 시각적으로 확인
  5. 이미지와 텍스트를 함께 보고 기획 내용 정리
  6. 결과가 다르면(이미지 vs 텍스트) 원본 구조와 렌더링 차이를 기록하고 PowerPoint 확인 필요 여부 명시
