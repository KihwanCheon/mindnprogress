# 완료 이력 정리와 복원

문서 조회에 필요한 요약은 파일 변경을 확인하는 메모리 캐시로 읽는다. 원본 문서·카드·댓글·공유 지식·Git 커밋과 작업공간 파일은 정리 대상이 아니다. AI 위임 완료 사용자 알림은 새로 생성하지 않으며 기존 완료 알림만 제거한다. 차단·실패 알림과 상위 AI의 결과 전달·수신 경로는 유지한다.

## 삭제 조건

- 완료 후 마지막 변경·보고 보관·수신 확인·작업공간 완료 시각에서 **7일**이 지난 상세만 정리한다.
- 상위 대화와 결과 해시가 일치하는 명시적 수신 확인이 있어야 한다. 작업공간을 사용했다면 통합 완료와 반환도 확인한다. 수신 확인 근거가 없는 과거 기록은 자동 삭제하지 않는다.
- 실행·통합·복구·결과 정정·보고 대기 및 보존 중인 다른 요청이 참조하는 이력은 남긴다. 활성 lease, 통합 잠금, 원격 반환 미확인 lease도 남긴다.
- 삭제 직전 후보를 `data/_completed-ai-cleanup-backups/cleanup-*.json.gz`에 압축 저장한다. 파일 동기화와 압축 해제 후 SHA-256 대조에 성공해야 상세를 삭제한다. 실패하면 삭제를 보류하며 서버 기동은 계속한다.
- 복원본은 생성 후 **30일** 보관한다. 복원본은 일상 문서 조회·위임 폴링에 읽지 않는다. 만료되면 상세 결과를 복원할 수 없으므로 영구 보관이 필요한 결과는 해당 업무의 산출물로 별도 보관한다.
- 요청 ID·서명 등 최소 접수 확인 정보는 `_ai-request-receipts.json`에 남긴다. 늦은 동일 요청은 재실행하지 않고, 다른 내용으로 같은 ID를 사용하면 거부한다. 마지막 작업공간 배정 시각과 원격 generation·요청 ID도 유지한다. 유예기간만으로 중복 실행 방지를 대신하지 않는다.
- 정리는 시작 시와 15분 주기로 수행한다. `MNP_COMPLETED_AI_CLEANUP_DISABLED=1`이면 정리를 중지한다. 운영 설정이나 예약 작업 자체는 이 변경에서 수정하지 않는다.

## 복원 절차

복원본에는 삭제한 위임 상세와 완료 lease 원문, 삭제 직전 읽은 `job-results` 파일 원문이 들어 있다. 결과 재전달·하위 재실행·Git 재통합을 자동으로 수행하지 않는다.

1. 운영 재시작·종료 권한을 확인하고 자동 정리를 중지한다. 승인된 런타임 제어 절차로 정상 종료한다. 실행 중 상태 파일을 덮어쓰지 않는다.
2. 현재 데이터 파일과 복원본을 따로 보존한다. 필요한 복원본 한 개를 골라 다음 명령으로 **운영 디렉터리 밖의 새 폴더**에 복원 후보를 만든다.

   ```powershell
   node scripts/export-completed-ai-history.mjs --data-dir C:\경로\data --backup C:\경로\data\_completed-ai-cleanup-backups\cleanup-대상.json.gz --output-dir C:\Temp\mnp-restore-review
   ```

3. 이 명령은 운영 파일을 쓰지 않는다. 현재 존재하는 동일 ID가 우선이며 현재 활성 배정·잠금·중복 방지 정보는 보존한다. 완료 기록만 병합하는지 검토한 뒤 필요한 파일을 적용한다. 출력된 `job-results`도 현재 파일이 없을 때만 공유 저장소의 같은 디렉터리에 복원한다. 현재 없던 풀의 설정·정체성을 복원 후보만으로 새로 만들지 않는다.
4. 이전 코드로 롤백할 때는 그 코드가 최소 접수 확인 정보를 읽지 못할 수 있다. 삭제 이후 생성된 복원본을 모두 검토하여 필요한 완료 상세를 복구하거나, 최소 접수 확인 정보를 읽는 중복 방지 코드를 유지한 버전으로 롤백한다. 복원본이 만료된 상세는 되살릴 수 없으므로 이 경우 중복 방지 코드를 반드시 유지한다. 오래된 전체 상태 파일로 현재 상태를 통째로 교체하지 않는다.
5. 정상 시작 후 현재 실행·lease·미수신 보고가 유지되는지 확인한다. 복원 검토가 끝날 때까지 자동 정리를 중지하고, 이후 중지 설정을 해제한다.

운영 서버에 적용하기 전 격리된 데이터로 저장 실패, 재시작, 늦은 재접수, 현재 기록과의 복원 충돌, 활성 작업 보존을 검증한다.
